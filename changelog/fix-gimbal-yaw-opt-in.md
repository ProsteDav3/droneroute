- Fixed: the camera now keeps tracking the target for the whole orbit instead of framing it at the start and drifting off. Every exported `gimbalRotate` enabled the gimbal's **yaw** — an absolute compass command — which pinned the camera to one direction and overrode the aircraft's POI tracking for the rest of the flight. Yaw is now opt-in: an action that only asks for a pitch leaves the camera's left-right aim to the aircraft, matching the flight-verified file. The action editor gained a checkbox for the cases where a fixed gimbal direction really is wanted.
