- Fixed: an imported KMZ now keeps its waypoint actions' settings. The importer stored every action parameter under DJI's raw XML name (`wpml:gimbalPitchRotateAngle`), which nothing else in SkyRoute reads, so the next export quietly replaced each one with a default — the gimbal level at 0° instead of the planned angle, a 5 s hover instead of 3 s, and area focus with no area set. A video orbit imported back, switched to photo and uploaded flew exactly like that over the Congress Centre: the camera started level and the aircraft stopped facing the POI for the rest of the flight, while the same orbit created directly as a photo mission tracked it the whole way. Missions imported before this fix export correctly too — the old names are read at export time, so re-uploading them is enough.
