- Added: the DJI Cloud wayline library can be cleared in one go — **Smazat všechny mise** and **Smazat všechny segmenty**, counted separately so a 71-segment upload can be swept without touching the missions themselves. Each button only arms the action; a second, explicitly labelled button ("Opravdu smazat 71 segmentů") does it, so a stray click can't empty the library. Progress is shown while it runs, and a failed delete part-way through neither stops the sweep nor leaves phantom rows in the list.
